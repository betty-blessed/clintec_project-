# Clintec Ultrasound & X-Ray Website

A modern diagnostic imaging website built with Django and Bootstrap for Clintec Ultrasound & X-Ray Services. The website enables patients to learn about available imaging services, book appointments online and easily contact the clinic.

## Features
- Modern responsive homepage
- Hero image slider
- Ultrasound services
- Digital X-Ray services
- Detailed service pages
- Online appointment booking
- Interactive live chat with automated responses
- Floating 
 buttons
    - Contact
    - WhatsApp
    - Facebook
    - Instagram
    - TikTok
- Responsive navigation bar
- Django Admin dashboard for managing appointments
- Mobile-friendly design
